# Telegram-бот для записи в парикмахерскую

Телеграм-бот для онлайн-записи клиентов в салон красоты. Клиент выбирает услугу, дату и время прямо в чате — администратор получает готовую заявку. Бот работает 24/7 и разгружает телефон.

Подходит для парикмахерских, барбершопов, салонов красоты, маникюрных кабинетов и массажных студий — везде, где есть запись по времени.

---

## Что умеет

### Для клиента

- Запись за 4 шага: услуга, дата, время, контакты
- Календарь на 14 дней вперед с реальными свободными слотами
- Слоты по часу с 10:00 до 20:00, занятые слоты скрываются
- Просмотр своих записей и отмена в один клик
- Напоминание за день до визита
- Напоминание за час до визита

### Для администратора

- Просмотр всех активных записей командой `/admin`
- Подтверждение, отмена и отметка "выполнена"
- Уведомления о новых записях и отменах в реальном времени
- Управление полностью через Telegram, без веб-панели
- Поддержка нескольких администраторов одновременно

## Стек

- Python 3.10+
- pyTelegramBotAPI (telebot) — работа с Telegram Bot API
- Flask — прием вебхуков от Telegram
- SQLite — хранение записей и услуг
- gunicorn — продакшн-сервер
- Railway — хостинг

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Djin5926/parik-bot.git
cd parik-bot
```

### 2. Виртуальное окружение и зависимости

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Для Linux/macOS: вместо `venv\Scripts\activate` используйте `source venv/bin/activate`.

### 3. Переменные окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=1234567890:AA-your-token-here
ADMIN_IDS=123456789,987654321
WEBHOOK_URL=https://your-app.railway.app
PORT=8080
```

Свой Telegram ID можно узнать через бота [@userinfobot](https://t.me/userinfobot).

### 4. Запуск

```bash
python bot.py
```

---

## Деплой на Railway

1. Форкните репозиторий.
2. Зайдите на [railway.app](https://railway.app), создайте проект через Deploy from GitHub.
3. Добавьте переменные окружения: `BOT_TOKEN`, `ADMIN_IDS`, `WEBHOOK_URL`, `PORT`.
4. Railway выдаст публичный URL — вставьте его в `WEBHOOK_URL`.

Альтернативы: Render, Fly.io, любой VPS с systemd и nginx.

## 🛡️ Безопасность и эксплуатация (Production Setup)

Проект развернут на VPS (Ubuntu 22.04) и настроен для работы в режиме 24/7 (production-ready).

### 🔐 Безопасность
- **SSH Hardening:** Вход по паролю отключен. Root-логин запрещен (`PermitRootLogin no`). Доступ возможен только по SSH-ключу (Ed25519).
- **Fail2ban:** Настроен SSH-джейл для защиты от брутфорса.
- **Секреты:** Все чувствительные данные (токен бота, ID админов) вынесены в файл `.env`. Файл исключен из Git (`.gitignore`), права доступа `600`.
- **SSL:** Настроен автоматический выпуск и продление сертификатов Let's Encrypt (Certbot) для работы Telegram Webhook по HTTPS.
- **Сетевая защита:** UFW (файрвол) разрешает только порты 2222 (SSH) и 80/443 (Nginx). Сам бот (Flask) слушает только `127.0.0.1:8080` и недоступен из интернета напрямую.

### ⚙️ Эксплуатация
- **Systemd:** Бот запущен как системная служба (`parikbot.service`) под отдельным непривилегированным пользователем `botuser`. Настроен автоперезапуск при падениях (`Restart=always`).
- **Логирование:** Логи пишутся в `journald` с ограничением максимального размера (500 МБ), чтобы не забивать диск.
- **Бэкапы БД:** Настроено ежедневное резервное копирование базы данных SQLite в 03:00 с ротацией (хранение 30 дней).
