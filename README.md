# Telegram-бот для записи в парикмахерскую

Телеграм-бот для онлайн-записи клиентов в салон красоты. Клиент выбирает услугу, дату и время прямо в чате — администратор получает готовую заявку. Бот работает 24/7 и разгружает телефон.

Подходит для парикмахерских, барбершопов, салонов красоты, маникюрных кабинетов и массажных студий — везде, где есть запись по времени.

---

## Что умеет

### Для клиента

- Запись за 4 шага: услуга, дата, время, контакты
- Календарь на 14 дней вперед с реальными свободными слотами
- Слоты по часу с 10:00 до 20:00, занятые слоты скрываются
- Просмотр своих записей и отмена в один клик
- Напоминание за день до визита
- Напоминание за час до визита

### Для администратора

- Просмотр всех активных записей командой /admin
- Подтверждение, отмена и отметка "выполнена"
- Уведомления о новых записях и отменах в реальном времени
- Управление полностью через Telegram, без веб-панели
- Поддержка нескольких администраторов одновременно

## Стек

- Python 3.10+
- pyTelegramBotAPI (telebot) — работа с Telegram Bot API
- Flask — прием вебхуков от Telegram

## Быстрый старт

### 1. Клонировать репозиторий

git clone https://github.com/Djin5926/parik-bot.git
cd parik-bot

### 2. Виртуальное окружение и зависимости

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

### 3. Переменные окружения

Создайте файл .env в корне проекта:

BOT_TOKEN=1234567890:AA-your-token-here
ADMIN_IDS=123456789,987654321
WEBHOOK_URL=https://your-app.railway.app
PORT=8080

Свой Telegram ID можно узнать через бота @userinfobot.

### 4. Запуск

python bot.py

---

## Деплой на Railway

1. Форкните репозиторий.
2. Зайдите на railway.app, создайте проект через Deploy from GitHub.
3. Добавьте переменные окружения: BOT_TOKEN, ADMIN_IDS, WEBHOOK_URL, PORT.
4. Railway выдаст публичный URL — вставьте его в WEBHOOK_URL.

Альтернативы: Render, Fly.io, любой VPS с systemd и nginx.

## Безопасность

- Токен бота, ID админов и URL вебхука — только через переменные окружения
- config.json добавлен в .gitignore, в репозиторий не попадает
- Перед записью проверяется, что слот свободен — два клиента не займут одно время
- Валидация имени и телефона на стороне бота
